# Order corpus.
#
# Every line is `expected_action | order as a person would actually type it`.
# The expectation is the ACTION the game executes, not the intent the parser
# chose, because two paths can reach the same command and only the outcome
# matters.
#
# These are written to be hostile in the ways real input is hostile: typos,
# phonetic spelling, politeness, British spelling, naval slang, wrong case,
# missing punctuation, and orders phrased as questions, complaints or panic.
#
# tests/lang.test.js runs every line and fails below the coverage floor. When a
# line here fails, the fix belongs in src/lang/lexicon.js, not in this file —
# deleting an awkward line to make the number go up defeats the entire purpose
# of having the file.
